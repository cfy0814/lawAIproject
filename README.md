# 法律咨询聊天机器人 

基于大模型 + RAG 架构的智能法律咨询系统，课程大模型应用开发项目，支持在线大模型问答 + 本地 RAG 检索增强双模式、多轮上下文对话、法律场景分类、对话日志持久化存储。

## 📌 项目简介

随着大模型在垂直领域落地普及，普通民众存在律师咨询成本高、法律知识匮乏、维权流程复杂等痛点。本项目开发法律咨询聊天机器人，以低成本、7×24 小时全天候为用户提供普惠式基础法律服务，覆盖劳动纠纷、婚姻家庭、借贷、交通事故、侵权责任、消费维权六大高频法律场景。

系统采用前后端分离架构，整合 FastAPI 后端、MySQL 数据库、Chroma 向量库、Ollama 本地大模型、智谱 GLM-4-Flash 在线大模型，实现法律文本预处理、结构化解析、RAG 法条检索、多轮对话记忆、前端可视化交互、压力测试与性能分析完整能力。

## 🛠 技术栈

### 后端技术

- 框架：FastAPI（异步接口、跨域处理、请求路由）
- 大模型：智谱 GLM-4-Flash（云端 API）、Qwen2.5:1.5b（Ollama 本地部署）
- 向量库：ChromaDB（本地 RAG 知识库）
- 数据库：MySQL（对话日志持久化）
- 自然语言处理：Jieba 分词、正则文本清洗、关键词提取、意图分类、实体识别
- 工具：LangChain、Pandas、Matplotlib、多线程压力测试

### 前端技术

- 基础：HTML + CSS + JavaScript
- 交互：原生 AJAX 请求、分类导航、聊天窗口、模型切换、历史对话展示

## 🎯 核心功能

1. 法律数据预处理

   原始法律文本清洗、去噪、去重、过滤无效短句，生成标准化法律数据集。

2. 法律文本结构化

   自动意图场景分类、法律实体识别、关键词提取，非结构化文本转结构化 CSV 数据。

3. 双模式智能问答

   - 云端模式：调用智谱 GLM-4-Flash 大模型 API，专业合规法律咨询
   - 本地 RAG 模式：Chroma 向量库检索相关法条，注入提示词减少模型幻觉

4. 多轮上下文对话

   基于user_id + 咨询分类

   维护会话历史，支持指代消解、连续对话记忆。

5. MySQL 数据持久化

   存储用户 ID、咨询分类、对话角色、内容、时间，支持历史对话回溯。

##  环境部署与运行

### 1. 环境依赖安装

```
pip install -r requirements.txt
```

### 2. 前置准备

1. 安装并启动 **MySQL**，创建数据库 `legal_bot_db`，执行项目中`chat_logs`建表语句；
2. 安装 **Ollama** 并拉取模型：`ollama pull qwen2.5:1.5b`；
3. 配置智谱 API Key（填入`llm_service.py`对应位置）；
4. 修改`db_manager.py`中 MySQL 账号密码为本地配置。

### 3. 数据预处理（首次运行必执行）

```
# 文本清洗去重
python src/data_clean.py
# 文本结构化、生成CSV数据集
python src/data_struct.py
# 自动构建Chroma向量库
python src/rag_retriever.py
```

### 4. 启动后端服务

```
python main.py
```

后端默认运行地址：`http://127.0.0.1:5000`

### 5. 启动前端

直接打开 `static/index.html` 即可进入聊天界面，选择法律分类、切换在线 / 本地模型开始咨询。

## 📊 系统性能测试

- 单轮平均响应时间：**1.5s**
- 10 路并发平均响应时间：**87.21s**
- 接口请求成功率：**100%**
- 结论：系统稳定性良好，高并发受限于大模型 API 串行排队，可引入 Redis 缓存优化响应速度。

## 🧩 系统架构
<img width="756" height="364" alt="image" src="https://github.com/user-attachments/assets/baa0e5c1-0a66-46ef-8696-621cea804f68" />

整体采用四层架构：
- **应用层**：Web 前端交互界面
- **服务层**：FastAPI 后端接口、业务逻辑调度
- **存储层**：MySQL（对话日志）+ ChromaDB（向量知识库）
- **数据层**：法律原始数据集 + 结构化 CSV+Embedding 向量化数据

支持本地 RAG 检索与云端大模型双模式自由切换，完整实现检索 - 增强 - 生成业务闭环。

## ✅ 项目亮点

1. 处理485 万原始法律数据，清洗精选出 174 万条标准法律条文；
2. 自研法律专属提示词工程，严格约束回答合规性，不越权、不误导、不预测判决；
3. 基于用户 ID + 分类实现隔离式多轮会话记忆，对话连贯性强；
4. 全栈自主开发：数据处理→后端接口→RAG 检索→前端界面→测试可视化完整链路；
5. 轻量化易部署，可拓展至社区普法、校园法律服务等场景。

## 🔧 不足与后续优化方向

1. 并发性能优化：引入 Redis 缓存高频问答，减少模型重复调用；
2. 意图识别升级：替换关键词匹配为轻量级语义模型，提升理解精度；
3. 功能拓展：新增类案检索、法律文书模板生成、法律风险评估；
4. 后端异步优化：改造串行请求为异步并发，降低多用户访问延迟。
